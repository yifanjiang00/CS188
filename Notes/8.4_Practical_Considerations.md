# 8.4 实践注意事项

机器学习的实际应用需要考虑多种实践问题，包括数据预处理、模型选择、过拟合预防和性能评估。本节介绍在机器学习系统中实现有效性能的关键注意事项。

### 数据预处理
- **特征缩放（Feature Scaling）**：
  - 将特征标准化（如零均值、单位方差）或归一化（如缩放到 [0,1]），以确保不同尺度的特征对模型贡献均衡。
  - 例如，标准化公式：
    \[ x' = \frac{x - \mu}{\sigma} \]
    其中 $\mu$ 是均值，$\sigma$ 是标准差。
- **缺失值处理**：用均值、众数填充缺失值，或删除缺失数据。
- **特征工程**：创建新特征（如多项式特征）或选择重要特征以提高模型性能。

### 过拟合与正则化
- **过拟合（Overfitting）**：模型过于拟合训练数据，导致测试数据性能差。
- **正则化（Regularization）**：
  - 在损失函数中添加惩罚项，限制模型复杂性。例如，L2 正则化：
    \[ L = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2 + \lambda \|w\|^2 \]
    其中 $\lambda$ 控制正则化强度，$\|w\|^2 = \sum w_j^2$ 是权重范数。
  - 常见方法：L1 正则化（Lasso）、L2 正则化（Ridge）、Dropout（神经网络）。
- **交叉验证**：使用 K 折交叉验证评估模型泛化能力，将数据分为 K 个子集，轮流用 K-1 个子集训练，1 个子集测试。

### 模型选择与评估
- **评估指标**：
  - 分类：准确率、精确率、召回率、F1 分数。
  - 回归：均方误差（MSE）、均方根误差（RMSE）、平均绝对误差（MAE）。
- **超参数调优**：
  - 使用网格搜索（Grid Search）或随机搜索（Random Search）选择最优超参数，如学习率 $\alpha$ 或正则化参数 $\lambda$。
- **偏差-方差权衡**：
  - 高偏差：模型过于简单（如线性模型），欠拟合。
  - 高方差：模型过于复杂（如高阶多项式），过拟合。
  - 目标：选择适当复杂度的模型，平衡偏差和方差。

### 数据不平衡
- **问题**：某些类别样本远少于其他类别，导致模型偏向多数类。
- **解决方法**：
  - 重采样：过采样少数类（如 SMOTE）或欠采样多数类。
  - 加权损失：为少数类分配更高权重。
  - 数据增强：生成合成样本。

### 伪代码（K 折交叉验证）
```python
def k_fold_cross_validation(X, y, model, K):
    folds = split_data(X, y, K)  # 将数据分为 K 份
    scores = []
    for i in range(K):
        train_X = [X[j] for j in range(K) if j != i]
        train_y = [y[j] for j in range(K) if j != i]
        test_X, test_y = X[i], y[i]
        model.fit(train_X, train_y)
        score = model.evaluate(test_X, test_y)
        scores.append(score)
    return mean(scores)
```

### 应用
实践注意事项确保机器学习模型在实际场景中表现稳健，例如图像分类（数据增强）、欺诈检测（不平衡数据处理）、推荐系统（特征工程）。
