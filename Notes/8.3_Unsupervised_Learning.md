# 8.3 无监督学习

无监督学习从无标记数据中发现模式，目标是提取数据的结构或分布，例如聚类或降维。无监督学习不需要目标标签，适合探索性分析。

### 无监督学习的类型
- **聚类（Clustering）**：将数据分组为相似性高的簇，例如 K 均值聚类。
- **降维（Dimensionality Reduction）**：将高维数据投影到低维空间，例如主成分分析（PCA）。
- **密度估计**：学习数据的概率分布，例如高斯混合模型（GMM）。

### 常见算法
- **K 均值聚类**：
  - 目标：将 $n$ 个数据点分为 $K$ 个簇，最小化簇内方差：
    \[ J = \sum_{i=1}^n \sum_{k=1}^K r_{ik} \| x_i - \mu_k \|^2 \]
    其中 $r_{ik}$ 表示点 $x_i$ 是否属于簇 $k$，$\mu_k$ 是簇中心。
  - 步骤：随机初始化簇中心，迭代分配点到最近中心并更新中心。
- **主成分分析（PCA）**：
  - 目标：找到最大方差的方向，投影数据到低维空间。
  - 方法：计算协方差矩阵的特征向量，选取前 $k$ 个特征值对应的向量。
- **高斯混合模型（GMM）**：
  - 假设数据由多个高斯分布生成，使用期望最大化（EM）算法估计参数。

### 伪代码（K 均值）
```python
def k_means(X, K, iterations):
    centroids = random_init(X, K)  # 随机初始化 K 个中心
    for _ in range(iterations):
        clusters = assign_clusters(X, centroids)  # 分配点到最近中心
        centroids = update_centroids(X, clusters)  # 更新中心
    return clusters, centroids
```

### 挑战
- **超参数选择**：如 $K$ 的选择影响聚类质量。
- **初始条件敏感**：初始中心可能导致不同结果。
- **数据规模**：大规模数据可能需要高效算法，如 Mini-Batch K-Means。

### 应用
无监督学习用于客户分割（聚类）、图像压缩（降维）、异常检测（密度估计）等领域。它适合数据标签稀缺或需发现隐藏结构的场景。
