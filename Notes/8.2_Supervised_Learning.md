# 8.2 监督学习

监督学习从标记数据（输入-输出对）中学习模型，目标是预测新输入的输出。监督学习分为分类（预测离散标签）和回归（预测连续值）。

### 监督学习的框架
- **数据集**：$\{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}$，其中 $x_i$ 是特征向量，$y_i$ 是标签。
- **模型**：函数 $f(x; \theta)$，由参数 $\theta$ 定义，例如线性模型 $f(x) = w^T x + b$。
- **损失函数**：衡量预测 $\hat{y} = f(x)$ 与真实标签 $y$ 的差异，例如：
  - 均方误差（回归）：$L = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2$
  - 交叉熵损失（分类）：$L = -\sum_{i=1}^n y_i \log \hat{y}_i$
- **优化**：最小化损失函数，常用梯度下降：
  \[ \theta \gets \theta - \alpha \nabla_\theta L \]

### 常见算法
- **线性回归**：预测连续值，假设线性关系 $y = w^T x + b$。
- **逻辑回归**：预测二分类概率，使用 sigmoid 函数 $\sigma(z) = \frac{1}{1 + e^{-z}}$。
- **支持向量机（SVM）**：寻找最大间隔超平面，分类或回归。
- **决策树**：基于特征条件构建树状模型。
- **神经网络**：多层非线性模型，适合复杂任务。

### 伪代码（线性回归）
```python
def linear_regression(X, y, alpha, iterations):
    w = zeros(X.shape[1])  # 初始化权重
    b = 0  # 初始化偏置
    for _ in range(iterations):
        y_pred = X @ w + b  # 预测
        error = y_pred - y
        grad_w = X.T @ error / len(y)  # 权重梯度
        grad_b = mean(error)  # 偏置梯度
        w -= alpha * grad_w
        b -= alpha * grad_b
    return w, b
```

### 挑战
- **过拟合**：模型过于拟合训练数据，在测试数据上表现差。
- **特征选择**：选择合适的特征对性能至关重要。
- **数据质量**：噪声或不平衡数据可能降低模型准确性。

### 应用
监督学习用于垃圾邮件过滤（分类）、房价预测（回归）、医疗诊断（疾病预测）等领域。
