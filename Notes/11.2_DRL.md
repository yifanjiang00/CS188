# 11.2 深度强化学习

深度强化学习（Deep Reinforcement Learning, DRL）结合深度神经网络与强化学习，解决高维状态和动作空间中的决策问题。它在复杂环境中表现出色，如游戏和机器人控制。

### 深度强化学习的框架
- **问题**：在高维状态空间（如图像）或连续动作空间中学习最优策略。
- **方法**：
  - **深度 Q 学习（DQN）**：使用神经网络逼近 Q 函数：
    \[ Q(s, a; \theta) \approx Q^*(s, a) \]
    更新规则：
    \[ Q(s, a; \theta) \gets Q(s, a; \theta) + \alpha [r + \gamma \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta)] \]
    其中 $\theta^-$ 是目标网络参数。
  - **策略梯度方法**：直接优化策略 $\pi(a|s; \theta)$，目标函数：
    \[ J(\theta) = \mathbb{E} \left[ \sum_t \gamma^t r_t \right] \]
    梯度更新：
    \[ \theta \gets \theta + \alpha \nabla_\theta J(\theta) \]

### 关键技术
- **经验回放（Experience Replay）**：存储历史经验 $(s, a, r, s')$，随机采样训练，打破时间相关性。
- **目标网络**：使用固定参数的目标网络稳定训练。
- **探索策略**：如 $\epsilon$-贪心或噪声注入，平衡探索与利用。

### 伪代码（DQN）
```python
def dqn(env, alpha, gamma, epsilon, iterations):
    Q = initialize_neural_network()  # Q 网络
    Q_target = copy(Q)  # 目标网络
    replay_buffer = []
    for _ in range(iterations):
        s = env.reset()
        while not done:
            a = epsilon_greedy(Q, s, epsilon)
            r, s_next, done = env.step(a)
            replay_buffer.append((s, a, r, s_next))
            batch = sample(replay_buffer)
            update_Q(Q, Q_target, batch, alpha, gamma)
            s = s_next
        periodically_update(Q_target, Q)  # 更新目标网络
    return Q
```

### 应用
DRL 用于游戏 AI（AlphaGo）、机器人控制（机械臂操作）、自动驾驶（路径规划）。
