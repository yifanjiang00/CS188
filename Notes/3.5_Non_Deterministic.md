# 3.5 非确定性博弈

非确定性博弈（non-deterministic games）引入了随机性（如掷骰子、发牌），使得状态转换不仅取决于玩家的动作，还取决于随机事件。这类博弈需要扩展 Minimax 搜索以处理随机性。

### 非确定性博弈的形式化
非确定性博弈在标准博弈问题的基础上增加了一个随机玩家（chance player），其动作由概率分布决定。形式化包括：
- **状态空间**：包含所有可能状态。
- **动作**：包括玩家动作和随机事件（如掷骰子结果）。
- **转换模型**：状态转换概率化。例如，掷骰子后，状态以概率 $p_i$ 转移到 $s_i$。
- **效用函数**：定义在终止状态，反映玩家的收益。
- **期望效用**：由于随机性，算法优化的是期望效用而非确定值。

### 期望极小极大搜索（Expectiminimax Search）
期望极小极大搜索是 Minimax 的扩展，处理随机性：
- **Max 节点**：选择最大化值的动作：
  \[ V(s) = \max_{a \in \text{Actions}(s)} V(\text{Result}(s, a)) \]
- **Min 节点**：选择最小化值的动作：
  \[ V(s) = \min_{a \in \text{Actions}(s)} V(\text{Result}(s, a)) \]
- **Chance 节点**：计算后续状态的期望值：
  \[ V(s) = \sum_{s' \in \text{Results}(s)} P(s') \cdot V(s') \]
  其中 $P(s')$ 是转移到状态 $s'$ 的概率。

### 伪代码
```python
def expectiminimax(state):
    if terminal_test(state):
        return utility(state)
    if is_max_player(state):
        value = -∞
        for action in actions(state):
            value = max(value, expectiminimax(result(state, action)))
        return value
    elif is_min_player(state):
        value = +∞
        for action in actions(state):
            value = min(value, expectiminimax(result(state, action)))
        return value
    else:  # Chance 节点
        value = 0
        for outcome, prob in chance_outcomes(state):
            value += prob * expectiminimax(result(state, outcome))
        return value
```

### 效率与优化
- **时间复杂度**：$O(b^m N)$，其中 $b$ 是分支因子，$m$ 是深度，$N$ 是每个 Chance 节点的可能结果数。随机性显著增加计算量。
- **Alpha-Beta 剪枝**：可扩展到 Expectiminimax，但剪枝效果因随机性减弱。
- **蒙特卡洛方法**：在复杂非确定性博弈中（如扑克），可通过模拟随机结果估计值。

### 应用
非确定性博弈常见于：
- **纸牌游戏**：如扑克，发牌引入随机性。
- **骰子游戏**：如双陆棋，掷骰子决定可行动作。
- **部分可观察博弈**：如某些策略游戏，玩家无法完全了解状态。

期望极小极大搜索为非确定性博弈提供了理论框架，但实际应用中常需结合蒙特卡洛方法或其他近似技术。
