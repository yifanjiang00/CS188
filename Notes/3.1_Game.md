# 3.1 博弈问题

博弈问题是人工智能中一类重要的对抗性搜索问题，涉及多个智能体（玩家）在竞争环境中做出决策。博弈通常是零和博弈（zero-sum games），其中一个玩家的收益等于其他玩家的损失。

### 博弈问题的形式化
博弈问题可以形式化为以下组成部分：
- **状态空间（State Space）**：描述游戏的所有可能状态。例如，在国际象棋中，状态是棋盘上的所有棋子位置。
- **初始状态（Initial State）**：游戏开始时的状态，例如棋盘的开局布置。
- **玩家（Players）**：参与博弈的智能体，通常分为两个玩家（如 Max 和 Min）。
- **动作（Actions）**：每个玩家在给定状态下可以执行的操作。例如，在国际象棋中，移动一个棋子。
- **转换模型（Transition Model）**：描述动作如何改变状态。例如，移动一个棋子更新棋盘状态。
- **终止测试（Terminal Test）**：确定游戏是否结束。例如，国际象棋中的“将死”或“和棋”。
- **效用函数（Utility Function）**：为终止状态分配数值，表示每个玩家的收益。例如，Max 获胜为 +1，Min 获胜为 -1，和棋为 0。

### 零和博弈
在零和博弈中，玩家的效用之和为零：
\[ u_{\text{Max}}(s) + u_{\text{Min}}(s) = 0 \]
其中 $u_{\text{Max}}(s)$ 和 $u_{\text{Min}}(s)$ 分别是 Max 和 Min 在终止状态 $s$ 的效用。零和博弈的目标是最大化自己的效用，同时最小化对手的效用。

### 博弈问题的例子
- **国际象棋**：两个玩家轮流移动棋子，目标是“将死”对手的王。
- **井字棋（Tic-Tac-Toe）**：两个玩家在 3x3 网格上放置符号，目标是形成一行、一列或对角线的三个相同符号。
- **围棋**：玩家在棋盘上放置黑白棋子，目标是控制更多区域。
