# 3.2 极小极大搜索

极小极大搜索（Minimax Search）是一种用于零和博弈的对抗性搜索算法，旨在为当前玩家找到最优动作，假设对手总是做出最优反应。

### Minimax 算法
Minimax 算法通过递归计算状态的**值（value）**来选择动作：
- **终止状态**：直接返回效用函数的值 $u(s)$。
- **Max 玩家的状态**：选择使值最大的动作：
  \[ V(s) = \max_{a \in \text{Actions}(s)} V(\text{Result}(s, a)) \]
- **Min 玩家的状态**：选择使值最小的动作：
  \[ V(s) = \min_{a \in \text{Actions}(s)} V(\text{Result}(s, a)) \]
其中 $\text{Result}(s, a)$ 是执行动作 $a$ 后的状态。

### Minimax 的工作原理
- 从当前状态开始，构建一个搜索树，交替考虑 Max 和 Min 玩家的动作。
- 递归计算每个叶节点的效用值（终止状态）。
- 向上传播值：Max 节点选择最大值，Min 节点选择最小值。
- 最终选择使根节点值最大的动作。

### 伪代码
```python
def minimax(state):
    if terminal_test(state):
        return utility(state)
    if is_max_player(state):
        value = -∞
        for action in actions(state):
            value = max(value, minimax(result(state, action)))
        return value
    else:
        value = +∞
        for action in actions(state):
            value = min(value, minimax(result(state, action)))
        return value
```

### 局限性
- **时间复杂度**：$O(b^m)$，其中 $b$ 是分支因子，$m$ 是搜索树的深度。对于复杂游戏（如国际象棋），完整搜索不可行。
- **深度限制**：通常限制搜索深度，使用评估函数估计非终止状态的值（见 3.4 小节）。

Minimax 假设双方玩家都采取最优策略，适用于井字棋等简单游戏，但在复杂游戏中需要优化。
