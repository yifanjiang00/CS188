# 5.4 Q-Learning

Q-Learning 是一种无模型强化学习算法，属于时序差分（Temporal Difference, TD）学习方法，用于直接学习动作值函数 $Q(s,a)$，无需显式建模环境的转换概率或奖励函数。

### Q-Learning 原理
Q-Learning 学习最优动作值函数 $Q^*(s,a)$，表示在状态 $s$ 执行动作 $a$ 并遵循最优策略的期望累积折扣奖励。更新规则基于 TD 误差：
\[ Q(s,a) \gets Q(s,a) + \alpha \left[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \right] \]
其中：
- $r$ 是执行动作 $a$ 后获得的即时奖励。
- $s'$ 是下一状态。
- $\alpha \in (0,1]$ 是学习率，控制更新幅度。
- $\gamma \in [0,1)$ 是折扣因子，权衡即时与未来奖励。

### Q-Learning 算法
- **初始化**：$Q(s,a)$ 初始化为任意值（通常为 0）。
- **交互与更新**：
  - 在状态 $s$，选择动作 $a$（通常使用 $\epsilon$-贪心策略平衡探索与利用）。
  - 执行动作，观察奖励 $r$ 和下一状态 $s'$。
  - 更新 $Q(s,a)$ 按上述公式。
- **策略提取**：最优策略由 $Q^*$ 推导：
  \[ \pi^*(s) = \arg\max_a Q^*(s,a) \]

### 伪代码
```python
def q_learning(states, actions, alpha, gamma, epsilon):
    Q = {(s, a): 0 for s in states for a in actions(s)}  # 初始化 Q 表
    while True:
        s = get_current_state()
        a = epsilon_greedy(Q, s, epsilon)  # 选择动作
        r, s_next = environment.step(a)
        Q[(s, a)] += alpha * (r + gamma * max(Q[(s_next, a_next)] for a_next in actions(s_next)) - Q[(s, a)])
        s = s_next
        if converged:  # 收敛条件（如固定迭代次数或 Q 值稳定）
            break
    pi = {s: argmax(Q[(s, a)] for a in actions(s)) for s in states}
    return Q, pi
```

### 特点
- **无模型**：无需知道 $P(s'|s,a)$ 或 $R(s,a,s')$，直接从交互中学习。
- **收敛性**：在适当条件下（充分探索、$\alpha$ 逐渐减小），Q-Learning 收敛到最优 $Q^*$。
- **时间复杂度**：依赖于状态和动作空间大小 $|S| \cdot |A|$ 以及探索效率。
- **探索与利用**：$\epsilon$-贪心或软最大化（softmax）策略用于平衡探索与利用。

### 挑战
- **收敛速度**：在大型状态空间中，Q-Learning 可能收敛缓慢。
- **探索效率**：不佳的探索策略可能导致智能体无法发现最优动作。
- **函数逼近**：对于连续状态空间，需使用神经网络等逼近 $Q(s,a)$，如深度 Q-Learning（DQN）。

### 应用
Q-Learning 广泛用于游戏（Atari 游戏）、机器人控制、资源管理等领域。它简单且灵活，适合环境模型未知的场景。
