# 5.2 基于模型的学习

基于模型的强化学习（Model-Based Reinforcement Learning）通过学习环境模型（转换概率和奖励函数）来规划最优策略。智能体利用学到的模型执行 MDP 算法（如价值迭代或策略迭代）。

### 模型学习的原理
- **环境模型**：智能体通过与环境的交互估计：
  - 转换概率：$P(s'|s,a)$，从状态 $s$ 执行动作 $a$ 转移到 $s'$ 的概率。
  - 奖励函数：$R(s,a,s')$，转移的奖励。
- **学习方法**：
  - 记录每次交互 $(s, a, r, s')$。
  - 使用频率估计转换概率：$P(s'|s,a) \approx \frac{\text{计数}(s,a,s')}{\text{计数}(s,a)}$。
  - 平均奖励：$R(s,a,s') \approx \text{平均}(r \mid s,a,s')$。
- **规划**：使用学到的模型 $(P, R)$，通过价值迭代或策略迭代求解最优策略。

### 伪代码
```python
def model_based_rl():
    model = {'P': {}, 'R': {}}  # 初始化环境模型
    V = {s: 0 for s in states}  # 初始化值函数
    while not converged:
        s = get_current_state()
        a = choose_action(V, model)  # 基于当前模型和值函数选择动作
        r, s_next = environment.step(a)
        update_model(model, s, a, r, s_next)  # 更新 P 和 R
        V = value_iteration(model)  # 使用学到的模型进行规划
    return V, extract_policy(V, model)
```

### 优点与挑战
- **优点**：
  - 高效利用数据：通过模型规划，减少对环境的直接交互。
  - 可重用模型：学到的模型可用于不同任务。
- **挑战**：
  - 模型误差：学到的模型可能不准确，导致次优策略。
  - 计算复杂性：模型学习和规划可能需要大量计算资源。
  - 稀疏数据：初始交互数据不足时，模型可能不可靠。

### 应用
基于模型的强化学习适用于环境模型可学习且计算资源充足的场景，如机器人导航（学习地图）或简单游戏（学习规则）。
