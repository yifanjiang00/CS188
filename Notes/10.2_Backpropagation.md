# 10.2 反向传播

反向传播（Backpropagation）是训练神经网络的核心算法，通过梯度下降优化权重以最小化损失函数。

### 损失函数
- 损失函数衡量预测值 $\hat{y}$ 与真实值 $y$ 的差异，例如均方误差：
  \[ L = \frac{1}{n} \sum_{i = 1}^n (y_i - \hat{y}_i)^2 \]
- 目标：最小化 $L$ 关于权重 $W$ 和偏置 $b$ 的函数。

### 反向传播算法
1. **前向传播**：计算预测值 $\hat{y}$ 和损失 $L$。
2. **计算梯度**：通过链式法则计算损失对权重和偏置的梯度：
   \[ \frac{\partial L}{\partial W^{[l]}} \text{ 和 } \frac{\partial L}{\partial b^{[l]}} \]
3. **更新权重**：
   \[ W^{[l]} \gets W^{[l]} - \alpha \frac{\partial L}{\partial W^{[l]}} \]
   \[ b^{[l]} \gets b^{[l]} - \alpha \frac{\partial L}{\partial b^{[l]}} \]
   其中 $\alpha$ 是学习率。
4. 重复直到收敛。

### 伪代码
```python
def backpropagation(X, y, network, alpha, iterations):
    for _ in range(iterations):
        y_pred = forward_propagation(X, network)  # 前向传播
        loss = compute_loss(y, y_pred)
        gradients = compute_gradients(loss, network)  # 计算梯度
        update_weights(network, gradients, alpha)  # 更新权重和偏置
    return network
```

### 挑战
- **梯度消失**：深层网络中梯度可能接近零，导致权重更新缓慢。
- **局部最小值**：损失函数可能陷入非全局最优解。
- **计算成本**：梯度计算对大数据量和高维权重矩阵成本高。

### 应用
反向传播用于训练各种神经网络模型，如多层感知机（MLP）、卷积神经网络（CNN）、递归神经网络（RNN）。
