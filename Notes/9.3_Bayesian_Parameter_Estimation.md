# 9.3 贝叶斯参数估计

贝叶斯参数估计（Bayesian Parameter Estimation）通过贝叶斯方法估计模型参数的分布，而不仅是点估计。相比最大似然估计（MLE），它能更好地处理不确定性和小数据集。

### 参数估计的框架
- **模型**：假设数据 $D$ 由参数化模型 $P(D|\theta)$ 生成，例如高斯分布 $P(x|\mu, \sigma)$。
- **先验分布**：$P(\theta)$，表示参数 $\theta$ 的初始信念，例如正态分布。
- **似然函数**：$P(D|\theta)$，表示数据在给定参数下的概率。
- **后验分布**：根据贝叶斯定理：
  \[ P(\theta|D) = \frac{P(D|\theta)P(\theta)}{P(D)} \]
  其中 $P(D) = \int P(D|\theta)P(\theta) d\theta$ 是归一化常数。

### 共轭先验
- 为简化计算，选择与似然函数共轭的先验分布，使后验分布形式与先验相同。
- 示例：
  - 伯努利似然（二分类）：共轭先验为 Beta 分布。
  - 高斯似然：共轭先验为正态分布（均值）或逆伽马分布（方差）。
- 例如，伯努利似然 $P(x|\theta) = \theta^x (1-\theta)^{1-x}$，Beta 先验 $P(\theta) \propto \theta^{\alpha-1}(1-\theta)^{\beta-1}$，后验为：
  \[ P(\theta|D) \propto \theta^{N_1 + \alpha - 1} (1-\theta)^{N_0 + \beta - 1} \]
  其中 $N_1$ 和 $N_0$ 是正负样本数。

### 预测
- 对新数据 $x^*$ 的预测分布：
  \[ P(x^*|D) = \int P(x^*|\theta)P(\theta|D) d\theta \]
- 使用后验均值或众数进行点估计：
  \[ \hat{\theta} = \mathbb{E}[\theta|D] \text{ 或 } \arg\max_\theta P(\theta|D) \]

### 优点与挑战
- **优点**：
  - 提供参数的不确定性估计，适合小数据集。
  - 自然融入先验知识。
- **挑战**：
  - 计算后验分布可能需要数值方法（如 MCMC）。
  - 先验选择可能影响结果。

### 应用
贝叶斯参数估计用于统计建模（参数不确定性）、机器学习（正则化效果）、医疗诊断（疾病参数估计）等领域。
