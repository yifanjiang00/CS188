# 7.2 隐马尔可夫模型

隐马尔可夫模型（Hidden Markov Models, HMMs）是一种概率模型，用于建模时间序列中的隐藏状态和观测序列。HMM 假设状态具有马尔可夫性质，且观测仅依赖于当前状态。

### HMM 的形式化
HMM 由以下部分组成：
- **隐藏状态（Hidden States）**：$X_t \in \{x_1, x_2, \dots\}$，随时间 $t$ 演变。
- **观测（Observations）**：$O_t \in \{o_1, o_2, \dots\}$，由隐藏状态生成。
- **转移概率（Transition Probabilities）**：$P(X_{t+1} | X_t)$，表示状态之间的转移概率。
- **发射概率（Emission Probabilities）**：$P(O_t | X_t)$，表示给定状态下观测的概率。
- **初始状态分布**：$P(X_1)$，表示初始状态的概率。

联合概率分布为：
\[ P(X_1, \dots, X_T, O_1, \dots, O_T) = P(X_1) P(O_1|X_1) \prod_{t=2}^T P(X_t|X_{t-1}) P(O_t|X_t) \]

### 推理任务
- **滤波**：计算 $P(X_t | O_1, \dots, O_t)$，使用前向算法（Forward Algorithm）。
- **平滑**：计算 $P(X_k | O_1, \dots, O_T)$，使用前向-后向算法（Forward-Backward Algorithm）。
- **最可能序列**：计算 $\arg\max_{X_1, \dots, X_T} P(X_1, \dots, X_T | O_1, \dots, O_T)$，使用维特比算法（Viterbi Algorithm）。

### 前向算法（伪代码）
```python
def forward_algorithm(observations, hmm):
    alpha = {}  # alpha[t][x] = P(X_t=x, O_1, ..., O_t)
    for t in range(1, len(observations) + 1):
        for x in hmm.states:
            if t == 1:
                alpha[t][x] = hmm.initial_prob[x] * hmm.emission_prob[x][observations[0]]
            else:
                alpha[t][x] = sum(alpha[t-1][x_prev] * hmm.transition_prob[x_prev][x]
                                  for x_prev in hmm.states) * hmm.emission_prob[x][observations[t-1]]
    return alpha
```

### 应用
HMM 广泛用于语音识别（建模语音序列）、生物信息学（基因序列分析）、手势识别等领域。它们适合离散状态和观测的动态系统。
