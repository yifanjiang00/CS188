# 6.4 贝叶斯网络中的推理

贝叶斯网络（Bayes’ Nets）提供了一种紧凑的联合概率分布表示，推理的目标是根据网络结构和已知证据计算特定变量的概率。本节介绍贝叶斯网络中的主要推理方法。

### 推理任务
贝叶斯网络推理通常包括以下任务：
- **边际概率（Marginal Probability）**：计算某个变量的概率，如 $P(X_i)$。
- **条件概率（Conditional Probability）**：给定证据变量 $E = e$，计算查询变量 $Q$ 的概率，如 $P(Q|E=e)$。
- **最大后验概率（MAP）**：寻找变量的最可能赋值，如 $\arg\max_{X_i} P(X_i|E=e)$。

### 精确推理
精确推理通过直接计算联合概率分布来获得答案。常用方法包括：
- **枚举法（Enumeration）**：
  - 对联合概率分布求和，计算边际或条件概率。例如：
    \[ P(Q|E=e) = \frac{P(Q, E=e)}{\sum_{Q'} P(Q', E=e)} \]
  - 使用贝叶斯网络的链式法则分解：
    \[ P(X_1, \dots, X_n) = \prod_{i=1}^n P(X_i | \text{Parents}(X_i)) \]
  - 计算复杂度为 $O(2^n)$，对大型网络不可行。
- **变量消除法（Variable Elimination）**：
  - 系统地消去非查询和非证据变量，减少计算量。
  - 步骤：
    1. 根据查询变量和证据变量选择消除顺序。
    2. 对每个无关变量求和，生成因子（factor）。
    3. 合并因子，计算最终概率。
  - 复杂度依赖于网络结构和消除顺序，通常远低于枚举法。
  - 示例：计算 $P(A|B=1)$，消除无关变量 $C, D$：
    \[ P(A|B=1) = \sum_{C,D} P(A,B=1,C,D) \]

### 近似推理
对于复杂网络，精确推理可能计算成本过高，需使用近似方法：
- **抽样法（Sampling）**：
  - **前向抽样**：根据网络的条件概率分布生成样本，估计概率。
  - **似然加权（Likelihood Weighting）**：对证据变量固定值，生成加权样本，提高效率。
  - **吉布斯抽样（Gibbs Sampling）**：一种马尔可夫链蒙特卡洛（MCMC）方法，通过迭代更新变量值生成样本。
- **特点**：
  - 近似推理牺牲精度换取效率，适合大规模网络。
  - 精度随样本数增加而提高，但可能需要大量样本。

```python
def variable_elimination(query, evidence, bayes_net):
    factors = []
    for var in bayes_net.variables:
        if var not in query and var not in evidence:
            factors.append(make_factor(var, evidence, bayes_net))
    for var in elimination_order:
        factors = sum_out(var, factors)  # 消去变量
    result = pointwise_product(factors)  # 合并因子

```

### 应用
贝叶斯网络推理用于医疗诊断（推断疾病概率）、故障检测（定位故障原因）、推荐系统（预测用户偏好）。精确推理适合小型网络，近似推理适用于复杂场景。
