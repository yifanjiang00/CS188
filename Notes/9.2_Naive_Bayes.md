# 9.2  朴素贝叶斯

朴素贝叶斯（Naive Bayes）是一种简单而高效的贝叶斯学习算法，广泛用于分类任务。它基于条件独立假设，简化概率计算。

### 朴素贝叶斯模型
- **问题**：给定特征向量 $x = (x_1, x_2, \dots, x_n)$，预测类别 $y$。
- **贝叶斯定理**：
  \[ P(y|x) = \frac{P(x|y)P(y)}{P(x)} \]
  其中 $P(x) = \sum_y P(x|y)P(y)$ 是归一化常数。
- **朴素假设**：给定类别 $y$，特征 $x_1, x_2, \dots, x_n$ 条件独立：
  \[ P(x|y) = \prod_{i=1}^n P(x_i|y) \]
- **分类规则**：选择最大后验概率的类别：
  \[ y^* = \arg\max_y P(y) \prod_{i=1}^n P(x_i|y) \]

### 参数估计
- **先验概率**：$P(y)$，通过训练数据中类别频率估计：
  \[ P(y) = \frac{\text{计数}(y)}{\text{总样本数}} \]
- **条件概率**：$P(x_i|y)$，根据特征类型选择适当模型：
  - 离散特征：使用频率估计，如 $P(x_i|y) = \frac{\text{计数}(x_i, y)}{\text{计数}(y)}$。
  - 连续特征：假设高斯分布，估计均值和方差。
- **平滑**：为避免零概率，使用拉普拉斯平滑：
  \[ P(x_i|y) = \frac{\text{计数}(x_i, y) + 1}{\text{计数}(y) + k} \]
  其中 $k$ 是特征值数量。

### 伪代码
```python
def naive_bayes_train(X, y):
    prior = {}  # P(y)
    cond_prob = {}  # P(x_i|y)
    for y_val in unique(y):
        prior[y_val] = count(y_val, y) / len(y)
        for i in range(X.shape[1]):
            cond_prob[(i, y_val)] = estimate_conditional_prob(X[:, i], y, y_val)
    return prior, cond_prob

def naive_bayes_predict(x, prior, cond_prob):
    scores = {}
    for y_val in prior:
        score = log(prior[y_val])
        for i, x_i in enumerate(x):
            score += log(cond_prob[(i, y_val)][x_i])
        scores[y_val] = score
    return argmax(scores)
```

### 优点与局限
- **优点**：
  - 计算效率高，适合高维数据。
  - 对小数据集有效，鲁棒性强。
- **局限**：
  - 条件独立假设可能不成立，导致模型偏差。
  - 对特征分布的建模（如高斯假设）可能不准确。

### 应用
朴素贝叶斯用于文本分类（垃圾邮件过滤）、情感分析、文档分类等领域，因其简单性和高效性受到青睐。
