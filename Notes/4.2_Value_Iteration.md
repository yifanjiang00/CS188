# 4.2 价值迭代

价值迭代（Value Iteration）是一种动态规划算法，用于求解 MDP 的最优策略和值函数。它通过迭代更新状态值来逼近最优值函数 $V^*$。

### 价值迭代算法
价值迭代基于贝尔曼最优方程，迭代更新每个状态的值：
\[ V_{k+1}(s) = \max_a \sum_{s'} P(s'|s,a) [R(s,a,s') + \gamma V_k(s')] \]
- **初始化**：设置初始值函数 $V_0(s) = 0$（或任意值）。
- **更新**：对每个状态 $s$，计算新的值 $V_{k+1}(s)$。
- **收敛**：当值函数变化小于某个阈值 $\epsilon$（即 $\max_s |V_{k+1}(s) - V_k(s)| < \epsilon$），停止迭代。
- **提取策略**：从最终值函数 $V^*$ 提取最优策略：
  \[ \pi^*(s) = \arg\max_a \sum_{s'} P(s'|s,a) [R(s,a,s') + \gamma V^*(s')] \]

### 伪代码
```python
def value_iteration(mdp, epsilon):
    V = {s: 0 for s in mdp.states}  # 初始化值函数
    while True:
        V_new = {}
        delta = 0
        for s in mdp.states:
            V_new[s] = max(sum(p * (r + gamma * V[s_next]) 
                               for s_next, p, r in mdp.transitions(s, a))
                           for a in mdp.actions(s))
            delta = max(delta, abs(V_new[s] - V[s]))
        V = V_new
        if delta < epsilon:
            break
    pi = {s: argmax(sum(p * (r + gamma * V[s_next]) 
                        for s_next, p, r in mdp.transitions(s, a))
                  for a in mdp.actions(s)) for s in mdp.states}
    return V, pi
```

### 特点
- **收敛性**：价值迭代保证收敛到最优值函数 $V^*$，因为贝尔曼算子是收缩映射。
- **时间复杂度**：每次迭代为 $O(|S|^2 |A|)$，其中 $|S|$ 是状态数，$|A|$ 是动作数。迭代次数取决于 $\gamma$ 和 $\epsilon$。
- **空间复杂度**：$O(|S|)$，存储值函数。

### 应用
价值迭代适用于状态空间有限的 MDP，如网格世界导航或简单机器人控制问题。对于大规模问题，可能需要近似方法。
