# 5.3 无模型学习

无模型强化学习（Model-Free Reinforcement Learning）直接从与环境的交互中学习策略或值函数，而不显式建模环境的转换概率或奖励函数。这种方法适合环境模型难以获取的场景。

### 无模型学习的方法

- **基于价值的（Value-Based）**：学习值函数（如 $V(s)$ 或 $Q(s,a)$），然后推导策略。例如，Q-Learning（见 5.4 小节）。
- **基于策略的（Policy-Based）**：直接优化策略 $\pi(a|s)$，通常通过策略梯度方法。
- **演员-评论家方法（Actor-Critic）**：结合基于价值和基于策略的方法，演员优化策略，评论家估计值函数。

### 蒙特卡洛方法

蒙特卡洛方法通过采样完整回合（episode）来估计值函数：

- **过程**：
  - 运行一个回合，记录状态、动作、奖励序列：$(s_1, a_1, r_1, s_2, a_2, r_2, \dots)$.
  - 计算回合的回报：$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \dots$。
  - 更新值函数：$V(s_t) \gets V(s_t) + \alpha (G_t - V(s_t))$。
- **特点**：
  - 无需环境模型，适合非马尔可夫环境。
  - 需要完整回合，适合回合制任务（如游戏）。

### 时序差分学习（Temporal Difference, TD）

TD 学习结合蒙特卡洛和动态规划，通过部分回合更新值函数：

- **TD(0)**：
  - 更新规则：$V(s) \gets V(s) + \alpha [r + \gamma V(s') - V(s)]$。
  - 使用单步奖励和下一状态的估计值。
- **特点**：
  - 无需完整回合，适合连续任务。
  - 比蒙特卡洛更快收敛，但可能对噪声敏感。

### 探索与利用

无模型学习需要平衡探索（exploration，尝试新动作）和利用（exploitation，选择已知最优动作）：

- **$\epsilon$-贪心策略**：以概率 $\epsilon$ 随机选择动作，否则选择最优动作。
- **UCB（Upper Confidence Bound）**：优先选择不确定性高但潜力大的动作。

### 应用

无模型强化学习广泛用于游戏（如 Atari）、机器人控制、自动驾驶，因其无需环境模型，适应性强。
