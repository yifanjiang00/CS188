# 4.3 策略迭代

策略迭代（Policy Iteration）是求解 MDP 最优策略的另一种动态规划算法，通过交替进行策略评估和策略改进来找到最优策略 $\pi^*$。

### 策略迭代算法
策略迭代包括两个步骤：
1. **策略评估（Policy Evaluation）**：
   - 给定策略 $\pi$，计算其值函数 $V^\pi(s)$，通过解线性方程组：
     \[ V^\pi(s) = \sum_{s'} P(s'|s,\pi(s)) [R(s,\pi(s),s') + \gamma V^\pi(s')] \]
   - 或者通过迭代更新：
     \[ V_{k+1}(s) = \sum_{s'} P(s'|s,\pi(s)) [R(s,\pi(s),s') + \gamma V_k(s')] \]
2. **策略改进（Policy Improvement）**：
   - 根据当前值函数 $V^\pi$，更新策略：
     \[ \pi'(s) = \arg\max_a \sum_{s'} P(s'|s,a) [R(s,a,s') + \gamma V^\pi(s')] \]
   - 如果策略不再改变（即 $\pi' = \pi$），算法收敛到最优策略 $\pi^*$。

### 伪代码
```python
def policy_iteration(mdp):
    pi = {s: random.choice(mdp.actions(s)) for s in mdp.states}  # 随机初始化策略
    while True:
        # 策略评估
        V = policy_evaluation(pi, mdp)
        # 策略改进
        pi_new = {}
        unchanged = True
        for s in mdp.states:
            old_action = pi[s]
            pi_new[s] = argmax(sum(p * (r + gamma * V[s_next]) 
                                   for s_next, p, r in mdp.transitions(s, a))
                               for a in mdp.actions(s))
            if old_action != pi_new[s]:
                unchanged = False
        pi = pi_new
        if unchanged:
            break
    return V, pi

def policy_evaluation(pi, mdp, epsilon):
    V = {s: 0 for s in mdp.states}
    while True:
        V_new = {}
        delta = 0
        for s in mdp.states:
            a = pi[s]
            V_new[s] = sum(p * (r + gamma * V[s_next]) 
                           for s_next, p, r in mdp.transitions(s, a))
            delta = max(delta, abs(V_new[s] - V[s]))
        V = V_new
        if delta < epsilon:
            break
    return V
```

### 特点
- **收敛性**：策略迭代保证收敛到最优策略 $\pi^*$，通常比价值迭代需要更少的迭代。

### 应用
策略迭代适用于需要快速收敛到最优策略的 MDP 问题，如机器人路径规划或资源分配。与价值迭代相比，它在策略稳定后无需进一步优化值函数。
