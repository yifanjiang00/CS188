# 3.3 Alpha-Beta 剪枝

Alpha-Beta 剪枝是 Minimax 搜索的优化版本，通过避免探索无关的分支来提高效率，同时保证返回与 Minimax 相同的最优动作。

### Alpha-Beta 剪枝原理
- **Alpha**：Max 玩家在搜索过程中能保证的最小值（初始为 $-\infty$）。
- **Beta**：Min 玩家在搜索过程中能保证的最大值（初始为 $+\infty$）。
- 在搜索过程中：
  - 如果 Max 节点的值小于等于 Alpha，Min 不会选择该分支，可以剪枝。
  - 如果 Min 节点的值大于等于 Beta，Max 不会选择该分支，可以剪枝。
- 通过维护 Alpha 和 Beta 值，算法跳过不会影响最终决策的分支。

### 伪代码
```python
def alpha_beta_search(state, alpha, beta):
    if terminal_test(state):
        return utility(state)
    if is_max_player(state):
        value = -∞
        for action in actions(state):
            value = max(value, alpha_beta_search(result(state, action), alpha, beta))
            alpha = max(alpha, value)
            if alpha >= beta:
                break  # Beta 剪枝
        return value
    else:
        value = +∞
        for action in actions(state):
            value = min(value, alpha_beta_search(result(state, action), alpha, beta))
            beta = min(beta, value)
            if alpha >= beta:
                break  # Alpha 剪枝
        return value
```

### 效率
- **最佳情况**：时间复杂度为 $O(b^{m/2})$，显著优于 Minimax 的 $O(b^m)$。
- **最差情况**：仍为 $O(b^m)$，但实际中剪枝通常大幅减少计算量。
- 效率依赖于动作的排序：优先考虑可能导致剪枝的动作（如高价值的 Max 动作或低价值的 Min 动作）。

### 应用
Alpha-Beta 剪枝广泛用于国际象棋、围棋等游戏的 AI 系统。它在保持最优性的同时显著减少计算开销，适合实时决策。
